# 📚 Book Selling Project (React)

A modern **Book Selling Web Application** built using **React (Vite)** and **JSON Server**.  
The project allows users to view books, manage a cart, and simulates backend APIs using JSON Server.

---

## 🚀 Features

- 📖 View list of available books
- 🛒 Add books to cart
- 👤 User & Admin mock data support
- 🔄 REST API integration using JSON Server
- ⚡ Fast development with Vite
- 📱 Responsive UI

---

## 🛠️ Tech Stack

- **Frontend:** React, Vite, JavaScript, HTML, CSS
- **Backend (Mock):** JSON Server
- **HTTP Client:** Axios
- **Version Control:** Git & GitHub
